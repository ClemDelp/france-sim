Documentation de France·Sim

France·Sim est un jeu de gestion de la France, construit sur un vrai modèle économique, social et climatique. Tout le modèle est ouvert : ses chiffres et ses règles sont dans des fichiers que chacun peut lire, discuter et améliorer.

🎛️ Je veux améliorer le modèle, sans coder

Corriger un chiffre, proposer une meilleure source, ajuster une hypothèse. Un tableur suffit, et on peut tout faire depuis le site de GitHub.

 💻 Je veux développer le jeu

Architecture, moteur de simulation, couche de jeu, tests : tout ce qu’il faut pour ajouter un levier, un événement, un scénario ou un écran.

 🧠 Je veux comprendre comment ça marche

Les grandes boucles du modèle, en schémas : l’argent, la dette, les ménages, le climat, l’immigration, l’influence, les crises.

Démarrage rapide

Jouer et explorer, sans rien installer

Jouez en ligne sur clemdelp.github.io/france-sim (sur téléphone, le jeu s’installe comme une appli), ou lancez-le en local (ci-dessous). Dans le jeu, le bouton 🧠 Le modèle ouvre le graphe des causes, tous les paramètres (modifiables pour essayer) et le test « face au passé ».

Lancer le jeu sur son ordinateur

Il faut Node.js (version 20 ou plus récente), puis, dans un terminal, à la racine du dépôt :

npm install      # une seule fois
npm run dev      # lance le jeu sur http://localhost:5173
npm test         # vérifie que le modèle tient debout
npm run phone    # pour jouer depuis un téléphone sur le même Wi-Fi

Le jeu s’adapte au téléphone et s’installe comme une appli (hors ligne) : voir le README et le guide du développeur.

Le dépôt en un coup d’œil

Dossier ou fichier Ce qu’on y trouve Pour qui
modele/ Toutes les données et règles du modèle, en fichiers CSV : chiffres de 2025 et de 2000, comportements, tranches de ménages, tailles d’entreprises, monde, historique, graphe des causes. Tout le monde
src/model/ Le moteur de simulation (TypeScript), le rejeu du passé, l’analyse de solidité, les explications. Développeurs
src/game/ La couche de jeu : scénarios, élections, capital politique, conseillers, une du journal, succès. Développeurs
src/ui/, src/App.tsx L’interface (React). Développeurs
docs/ Cette documentation (pages HTML) et COMMENT-CA-MARCHE.md. Tout le monde
scripts/build-docs.mjs Fabrique le catalogue des paramètres à partir des CSV. Développeurs
.github/workflows/ci.yml Les vérifications automatiques lancées par GitHub à chaque proposition de modification. Tout le monde (le résultat)

Lire cette documentation

  • Sur votre ordinateur : ouvrez docs/index.html dans un navigateur (double-clic). Les schémas ont besoin d’une connexion Internet pour être dessinés ; sans connexion, leur texte reste lisible.
  • En ligne, avec GitHub Pages : dans les réglages du dépôt sur GitHub, Settings → Pages → Build and deployment, choisir la branche main et le dossier /docs. (Pour un dépôt privé, GitHub Pages demande une offre payante.)

Le principe qui guide tout le projet : un simulateur honnête montre des mécanismes et des ordres de grandeur, pas des prédictions. Chaque chiffre a une source ou est déclaré comme hypothèse, et chaque règle peut être discutée et changée. Les tests garantissent que les changements ne cassent pas la cohérence de l’ensemble.
